# Storage Estimator - Feature Version

## Purpose
A simple Python program that estimates how much storage is needed for a collection of files.

## How to Run
1. Make sure Python is installed.
2. Open a terminal in this folder.
3. Run: python storage_estimator.py
4. Enter the number of files and the average file size in MB when asked.

## Example Input/Output
    Storage Estimator
    -----------------
    Number of files: 100
    Average file size (MB): 2.5
    Number of files: 100
    Total storage needed: 250.0 MB
